Codex for Finance｜课前检查清单

适用范围

本清单用于 50 人线下培训。现场只有一位讲师，不安排逐台安装排障。学员应在课前完成 Codex Desktop 安装与登录；飞书 CLI 为进阶演示前置项，未配置成功的学员课堂先观看，会后按教程补齐。

学员课前 5 分钟检查

请在培训开始前完成以下检查。全部使用课程模拟文件，不要打开或复制真实业务材料。

1. 安装与登录

  • 从瓶子星球 Skill 市场下载并安装公司封装版 Codex Desktop。
  • 使用飞书认证完成登录。
  • 登录后能够看到 Codex 主界面和“新建任务”入口。
  • 系统已自动分配 API key；我没有在聊天、截图或文档中手工展示 API key。
  • 能正常新建一个空白 Task。

如果无法下载安装，先记录错误截图和时间，不要反复卸载。培训现场与已安装同事结对观看，课后集中处理。

2. 课程网站与实验材料

  • 可以打开本次培训网站。
  • 已从网站下载 codex-labs.zip 并解压，得到 codex-labs 课程材料文件夹。
  • 文件夹中至少包含以下模拟文件：
    • 01-operating-metrics.csv
    • 02-budget-variance.csv
    • 03-contract-risk.md
    • 04-tax-items.md
    • 05-admin-procurement.md
    • 06-management-report-template.md
    • 07-feishu-base.json
    • prompts.md
  • 我已确认实验包中没有真实合同、真实员工信息、真实客户信息或真实财务数据。

3. Workspace 读写测试

  • 在 Codex 中新建 Task，并将解压后的 codex-labs 文件夹设为 Workspace。
  • 复制下面的测试 Prompt：
请只读列出当前 Workspace 中的全部文件，不要修改、移动或创建任何文件。最后告诉我共识别到多少个文件。
  • Codex 能列出文件，没有报告路径或权限错误。
  • 我知道 Workspace 决定 Codex 可以读取和修改的本地范围。
  • 我没有把个人主目录、下载目录或真实业务共享盘直接设为练习 Workspace。

4. 飞书 CLI 连接

  • 我已阅读飞书社区参考教程。
  • 如计划课堂跟做，我已在课前完成 CLI、应用和授权配置。
  • 我有一个可测试的飞书文档或测试空间，不使用生产文档。
  • 我有一个可测试的飞书 Base，不使用真实生产 Base。
  • 我能在 Codex 中看到或调用 $lark-doc、$lark-base 等对应 Skills；实际名称以当前版本为准。
  • 写操作前，我会先要求 Codex 显示目标对象、写入范围、覆盖与通知影响。

飞书教程的界面、命令和权限流程可能随版本更新。课堂不集中处理应用审批、OAuth 或组织权限问题。

5. 网络与 Skill 来源

  • 可以访问内部 Skill 市场 https://skills.ijovo.com/。
  • 已知 GitHub 无法直接访问时，应先完成内部学习中心（Finance Learning Hub）的“科学上网”课程；入口不对外公开，请查看内部群公告或联系管理员。
  • 不在课堂临时下载来源不明的 Skill。
  • 安装第三方 Skill 前会检查作者、更新时间、LICENSE、权限、脚本、依赖与网络访问。
  • 我知道 Superpowers 是 GitHub 上的第三方 Skills / Plugin 项目，不是 Codex 内置功能。

6. 安全确认

  • 不把 API key、Token、密码、SSH key、Cookie 或验证码粘贴给 Codex。
  • 不使用未脱敏的合同、身份证、薪酬、客户、供应商、税务或银行数据。
  • 删除、覆盖、发送、发布、审批、权限变更和批量写入前，先查看影响范围并人工确认。
  • 关键数字会回到源文件核对，不把“生成成功”当作“结论正确”。

学员快速验收

完成以下动作即可判定“已准备好”：

打开 Codex → 新建 Task → 选择课程 Workspace
→ 只读列出课程材料文件 → 得到正常结果

请在培训开始前选择一种状态：

  • A｜完全 ready：Codex、实验包和飞书测试连接均可用。
  • B｜基础 ready：Codex 与实验包可用，飞书环节只观看。
  • C｜结对观看：Codex 尚未安装或登录失败，已找到结对同学。

常见问题与处理

症状 现场处理 课后处理
没有“新建任务”或界面不同 确认是否为公司封装版；跟随讲师按功能概念操作 更新到指定版本并重试
飞书登录成功但 Codex 未登录 退出并重新发起飞书认证一次 保存错误截图，按安装文档排查
无法读取实验目录 重新选择课程 Workspace，检查目录是否解压完整 检查权限、路径和文件编码
GitHub 无法访问 使用内部 Skill 市场与课程截图 先完成 Learning Hub 网络课程
Superpowers 调用失败 观看讲师预录结果，不临时改环境 检查 README、版本和安装范围
飞书写入权限不足 停止写入，只生成待写入本地文件 重新确认应用权限与测试对象授权
请求长时间运行 中止，缩小为单文件或单部门任务 查看日志，拆分任务重试
