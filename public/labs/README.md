# Codex 财运中心培训｜月度经营复盘 Lab

这是一套完整的虚构业务案例。你将让 Codex 读取多种格式的材料，完成跨团队分析、管理层汇报、交互网页、Skill 封装和飞书交付。

## 文件清单

| 文件 | 用途 |
|---|---|
| `01-operating-metrics.csv` | 核心经营 KPI、趋势与目标差异 |
| `02-budget-variance.csv` | 收入、成本、费用、利润的预算差异明细 |
| `03-contract-risk.md` | 合同验收、逾期应收、续约及采购合同风险 |
| `04-tax-items.md` | 税会差异、研发费用证据与发票事项 |
| `05-admin-procurement.md` | 行政采购预算、明细、流程与改进动作 |
| `06-management-report-template.md` | 管理层汇报固定结构及勾稽规则 |
| `07-feishu-base.json` | 飞书 Base 字段定义与行动台账模拟记录 |
| `prompts.md` | 可直接复制的基础、Superpowers、Subagents、Skill、网页和飞书 prompts |

## 建议练习顺序

1. 下载 `codex-labs.zip` 并解压，得到 `codex-labs` 课程材料文件夹（也可以逐个下载文件放进同一个文件夹）。
2. 在 Codex 中选择该文件夹作为 workspace。
3. 打开 `prompts.md`，先运行 Prompt 1，确认 Codex 可以读取文件。
4. 运行 Prompt 3，观察五个 Subagents 如何并行分析及合并结论。
5. 从 Prompt 4、5、6 中任选一个，产出管理层汇报、交互网页或新 Skill。
6. 已完成飞书 CLI 配置的学员，可继续运行 Prompt 7–10。

## 预期业务结论

- 营业收入为 1,280 万元，较目标少 70 万元。
- 毛利额为 384 万元，期间费用为 250 万元，经营利润为 134 万元。
- 经营利润较预算少 54.5 万元，由毛利少 34.5 万元与期间费用超预算 20 万元共同造成。
- 期末应收账款为 620 万元，其中合同 `CT-2026-041` 的 120 万元已逾期。
- 同一合同另有 60 万元因验收延后未确认收入，并产生税会差异管理需求。
- 行政采购预算 18 万元、实际 25 万元，超预算 7 万元；其中 5 万元存储扩容发票待更正。

## 验收标准

完成任意练习时，至少满足以下要求：

- Codex 明确列出实际读取的文件，不声称读取不存在的内容。
- 关键数字与“预期业务结论”一致，利润勾稽和采购加总正确。
- 结论附来源文件或事项编号；缺失信息标为“待确认”。
- 输出至少包含一个可下载的本地成果或一个新建的飞书成果。
- 使用 Subagents 时，能看到独立任务边界、各角色结果与主 Agent 整合。
- 使用飞书时，不修改既有业务文档或 Base，只操作本次新建的培训对象。
